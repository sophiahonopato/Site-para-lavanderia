# 🧺 Site para Lavanderia

Website desenvolvido para uma lavanderia, com foco na criação de uma interface simples, organizada e funcional para apresentar o serviço de forma digital.

## 💡 Sobre o projeto

O Site para Lavanderia foi desenvolvido como um projeto de Front-end para colocar em prática conceitos de desenvolvimento de páginas web e criação de interfaces.

A proposta foi transformar a ideia de uma lavanderia em uma presença digital, organizando as informações de maneira clara e criando uma experiência simples para o usuário.

## 🎯 Objetivos

- Criar uma página para uma lavanderia
- Desenvolver uma interface organizada e intuitiva
- Trabalhar estrutura e organização de conteúdo
- Praticar desenvolvimento Front-end
- Criar uma experiência adaptada para diferentes telas

## 🎨 Interface

O projeto foi desenvolvido pensando em:

- Organização das informações
- Hierarquia visual
- Facilidade de navegação
- Apresentação dos serviços
- Experiência do usuário
- Responsividade

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Vercel

## 📚 O que pratiquei

Durante o desenvolvimento, pude praticar conceitos importantes de Front-end, principalmente a construção de uma página desde sua estrutura até a apresentação visual.

Esse projeto também fez parte da minha evolução na criação de interfaces voltadas para situações e negócios reais.
